## Baldwin Monarch

My first attempt at creating a soundfont using my old and slightly out of tune Baldwin Monarch. I used a recording for almost every key (some had to be cut because of background noise).

There is a slight amount of noise that may be noticeable with headphones while many notes are playing.

There is also a slight quirk with one of the super low notes, it's not a bug, it's just how the piano sounds, and I felt like keeping it in for accuracy.

Will try to add more velocity layers in the future..

There is a demo file in this directory if you want to listen to it before downloading. 
Demo title is my own composition that should have a good range for testing.
